# Terminalia - Roadmap

## Version 0.1 - Engine Skeleton

Features:

- Solution structure.
- Core abstractions.
- Game loop.
- Scene.
- Entity.
- Components.
- Systems.
- Basic terminal renderer.
- Console input.
- Sample game starts.

## Version 0.2 - Movement and Collision

Features:

- Movement system.
- Collision system.
- Tile map.
- Map loading from JSON.
- Player cannot cross walls.

## Version 0.3 - Rendering Pipeline

Features:

- Frame buffer.
- Diff rendering.
- Layers.
- Camera.
- Text drawing.

## Version 0.4 - ASCII Assets

Features:

- Sprite loading.
- Animation loading.
- Animation system.
- Animated player or enemy.

## Version 0.5 - Gameplay Demo

Features:

- Health component.
- Enemy placeholder.
- Simple combat.
- HUD.
- Sample dungeon.

## Version 1.0 - Portfolio Release

Features:

- Polished README.
- Architecture documentation.
- Test coverage.
- GitHub Actions.
- Sample GIF.
- NuGet package optional.
- Release tag.
